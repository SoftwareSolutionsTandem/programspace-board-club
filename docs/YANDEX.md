# Яндекс Игры: требования и интеграция

Дата проверки: **2026-10-17**.

Способ проверки: **веб-поиск по официальным страницам**. Прямое чтение `yandex.ru` из среды разработки закрыто сетевой политикой. Поэтому все пункты ниже имеют статус «подтверждено поиском», и перед этапом 6 их нужно перечитать напрямую.

Метки: **[П]** — найдено на официальной странице (через поиск); **[Н]** — не проверено или известно только из вторичных источников.

## Подключение и запуск
- [П] SDK подключается скриптом по относительному пути `/sdk.js` с атрибутами `async` и `onload`; файл не скачивается. При локальной разработке путь проксируется локальным сервером. Инициализация — строго по странице «Подключение и использование» (п. 1.19.1); ошибки здесь — критичный пункт 1.1. — [Подключение и использование](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about), [Методы SDK](https://yandex.ru/dev/games/doc/ru/requirements/1/19)
- [П] `ysdk.features.LoadingAPI.ready()` **обязателен** в момент, когда игрок уже может начать игру (п. 1.19.2). — [Загрузка игры и разметка геймплея](https://yandex.ru/dev/games/doc/ru/sdk/sdk-gameready), [Release notes](https://yandex.ru/dev/games/doc/ru/release-notes)
- [П] `GameplayAPI.start()` и `stop()` необязательны, но если используются, то строго по описанию (п. 1.19.3). План: `start` — начало или возобновление партии, `stop` — пауза, экран результата, выход в меню.
- [П] События `game_api_pause` и `game_api_resume` необязательны, обработка по описанию (п. 1.19.4).

## Поведение
- [П] Звук ставится на паузу при показе рекламы и при потере фокуса. — [Требования к игре](https://yandex.ru/dev/games/doc/ru/concepts/requirements)
- [П] Язык определяется через `ysdk.environment.i18n.lang`.
- [П] В игру можно играть без входа в аккаунт. Вход через Яндекс ID — только по осознанному нажатию кнопки. — [Game requirements](https://yandex.com/dev/games/doc/dg/concepts/requirements.html)
- [П] На мобильных — полноэкранный режим, без искажений при повороте экрана.

## Реклама
- [П] Только через SDK. — [Реклама (SDK)](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv)
- [П] Частоту полноэкранной рекламы ограничивает платформа. При слишком частом вызове приходит `onClose` с `wasShown = false`.
- [П] Вызов по таймеру документация приводит как **неправильный** пример.
- [П] Rewarded-видео не ограничено по частоте. Награда выдаётся только в `onRewarded`.
- [Н] Конкретный минимальный интервал между полноэкранными показами в найденных материалах не назван.

## Сохранения
- [П] Данные игрока сохраняются на сервере Яндекса (player data). — [Данные игрока](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player), [Сохранение прогресса](https://yandex.ru/dev/games/doc/ru/requirements/1/9)
- [П для Defold / Н для JS] Лимит 200 КБ, параметр `flush`. — [Defold: данные игрока](https://yandex.ru/dev/games/doc/ru/sdk/defold/player-data)

## Размер и сборка
- [П] Все файлы игры — до 100 МБ. При превышении игра доступна только на ПК. — [Критерии модерации](https://yandex.ru/dev/games/doc/ru/concepts/criteria)
- [Н] Распакованный размер это или размер архива — источники расходятся.

## Покупки (не в MVP)
- [П] Покупки только через SDK. Подключаются в консоли один раз на аккаунт. — [О монетизации](https://yandex.ru/dev/games/doc/ru/services/about-monetization), [Инап-покупки](https://yandex.ru/dev/games/doc/ru/console/purchases)
- [П] Поддерживается самозанятость. Без неё выплата идёт как физлицу с удержанием 13–22%. — [Самозанятые](https://yandex.ru/dev/games/doc/ru/payments/self-employed)
