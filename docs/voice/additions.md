# Реплики партии к записи (ревизия голоса 2026-10-31, VOICE-ALL)

Новые реплики **партии** Агаты и Матвея, добавленные при ревизии голоса. Список собран из каталогов
`src/characters/<персонаж>/lines.ts` (реплики `S(...)` вне сценок). Реплики сценок «своей жизни» — отдельно, в
`docs/voice/scenes.md`.

**Записей нет ни одной.** Синтез, TTS и подстановка чужих записей не используются. Пока записи нет:
- новые ситуации уже распознаются в игре; персонаж отвечает мимикой, позой и жестом;
- если у события есть **запасная категория** (`Trigger.fallback`), звучит уже записанная реплика оттуда;
- реплика зазвучит сама, когда появится файл.

## Как добавить запись

1. Сохранить файл `assets-src/audio/ru/<персонаж>/<ID>.flac`: моно, 44,1–48 кГц, имя — точно ID, тишина по краям не больше 0,3 с.
2. В `src/characters/<персонаж>/lines.ts` заменить у реплики `S(...)` на `L(...)`. У Матвея ещё снять пометку «ожидает записи» в `docs/voice/matvey-script.md`.
3. Выполнить `node tools/audio/build-voice.mjs --character <персонаж>`. Получатся `public/audio/ru/<персонаж>/<ID>.opus` и `.m4a`, обновятся `manifest.json` и `assets/audio/LICENSES.md`.
4. Выполнить `npm run check`. Счётчики «записано реплик — N из M» в e2e (`tests/e2e/product.e2e.ts`) изменятся: обновить их.

## Как читать

- **Срочность записи:**
  - **A** — новая ситуация без единой записи или реплика, которая сейчас повторяется каждый раз;
  - **B** — разнообразие для частых событий, где записей 1–2.
- **Приоритет канала:** `result` > `greeting` > `reaction` > `idle`. **Шанс** — вероятность заговорить, когда событие случилось.
- **Длительность** — ориентир по тексту. Реплика не должна задерживать игру.
