# Сценки «своей жизни» — реплики для записи

Всего: **57 реплик**, 23 сценки.

Список новых реплик всех четырёх персонажей для сценок в паузах (D64, `docs/ART_STYLE.md` §5.6). **Записей нет ни одной** —
сценки уже идут в игре молча (движение, реквизит, мимика); реплика зазвучит сама, как только запись будет добавлена.

Как добавить запись: файл `assets-src/audio/ru/<персонаж>/<ID>.flac` (моно, 44,1–48 кГц, имя — точно ID) → в
`src/characters/<персонаж>/lines.ts` у реплики убрать пометку «ожидает записи» (`S(...)` → `L(...)`) → `node tools/audio/build-voice.mjs
--character <персонаж>` → `npm run check`. У Агаты, Матвея и Харитона — как их прежние записи; у Костяна это будут первые записи.

Длина — по смыслу сценки: обычно 1–3 с; сценка ждёт конца фразы, но не дольше 9 с.
