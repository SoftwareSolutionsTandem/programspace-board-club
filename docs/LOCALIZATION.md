# Локализация

## Сейчас
- Язык интерфейса — русский (`src/i18n/ru.json`).
- Все пользовательские строки — только через `t(key, params)` из `src/i18n`. Строки в компонентах напрямую не пишутся.
- Ключи — по экранам и областям: `app.*`, `start.*`, `table.*`, `error.*`, позже `durak.*`, `char.agata.*`.
- Параметры — `{name}` в строке и `t('key', { name: 'Агата' })`. Неизвестный параметр остаётся как есть (видно при проверке).
- Нет строки в текущем языке → берётся из русского; нет и там → выводится ключ (видно при проверке).
- Числа — `i18n.formatNumber()` (Intl.NumberFormat по текущему языку).

## Как добавить язык
1. Создать `src/i18n/<lang>.json` с теми же ключами.
2. Подключить словарь в `src/i18n/index.ts`: `createI18n({ ru, en }, 'ru')`.
3. На этапе 6 язык берётся из платформы (`ysdk.environment.i18n.lang`) через адаптер и передаётся в `i18n.setLanguage()`.

## Озвучка и язык
- Голоса раскладываются по языкам: `assets/audio/<lang>/<character>/` (см. `AUDIO.md` §8.2).
- Если для языка нет голосов персонажа, используется русская озвучка; субтитры (опция доступности) берутся из словаря текущего языка.
- Реплики и обращения гендерно-нейтральны во всех языках (пол игрока неизвестен).

## Ограничения
- Множественные формы («1 карта / 2 карты / 5 карт») пока не нужны; при появлении — `Intl.PluralRules` и ключи вида `key.one/few/many/other`.
