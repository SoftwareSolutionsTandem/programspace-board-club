# Аудио и озвучка персонажей

Статус: **подход утверждён 2026-10-17**. Этап VOICE-01 (§14): выбран бесплатный кандидат — локальная нейросетевая генерация Qwen3-TTS; инструменты генерации и сборки готовы. **Настоящих голосовых файлов в игре пока нет**: пробы ещё не созданы (веса модели недоступны из среды разработки) и не одобрены вами. До этого аудиосистема **не считается реализованной**, даже если код готов.

## 1. Принципы
1. Персонажи разговаривают **голосом**. Текстовые облачка как замена речи запрещены, в том числе в прототипах. Субтитры допустимы только как опция доступности, по умолчанию выключены.
2. Реплики — заранее подготовленные аудиофайлы в ресурсах игры. Во время игры нет обращений к TTS и другим внешним сервисам.
3. Уместность важнее количества: персонаж молчит чаще, чем говорит, и никогда не противоречит ситуации.
4. На каждый файл должны быть подтверждённые права на коммерческое использование (§9).
5. Настройки пользователя и системный беззвучный режим уважаются, обходить их нельзя (§7).

## 3. Демонстрационная библиотека (до одобрения голоса)

**Критерии оценки образца:**
- естественность русской речи: ударения, интонация, отсутствие «роботности»;
- соответствие образу;
- различимость эмоций в слепом прослушивании (назвать эмоцию без текста);
- смех и вздохи звучат живо;
- нет шумов, щелчков и эха;
- вы подтверждаете: «хочется слушать снова».

## 4. Способы получения голосов — сравнение
Оценки качества — ожидаемые, их нужно подтвердить образцами. Цены указаны ориентиром, без проверки. Условия сервисов меняются, поэтому перед генерацией нужно перечитать действующие и сохранить их копию (PDF с датой).

Общие предупреждения:
- Платный тариф **сам по себе не гарантирует** нужных прав. Читаем действующие условия конкретного сервиса и конкретного голоса на дату генерации.
- Клонирование голосов реальных людей без их письменного разрешения запрещено нашим правилом.
- Если оплата зарубежных сервисов из РФ недоступна, это практическое ограничение. Его надо учесть до выбора.

**Рекомендация:**
1. Провести два параллельных пробных образца на репликах 1, 4 и 8:
   - (а) 1–2 актёра по прослушиванию;
   - (б) один TTS-сервис, условия которого проверены и допускают игру.
2. Сравнить вслепую по критериям §3.
3. Для финальной озвучки ожидаю, что выиграет актёр, потому что смех и игра голосом — центральная часть концепции. Но решение принимаем по образцам.

## 5. Как получить файлы (инструкция для вас)
Ограничение: **в моём окружении нельзя записать или синтезировать голос.** Внешние TTS отсюда недоступны, микрофона нет. Фиктивную озвучку (тоны, «бормотание», пустые файлы) я делать не буду.

**Вариант «актёр»:**
1. Площадка: биржа фриланса или студия озвучания. Запрос: «женский характерный голос, бабушка, комедийная подача, игра для Яндекс Игр».
2. Отправить ТЗ (§6) и тексты реплик 1, 4 и 8 для прослушивания.
3. В договоре зафиксировать:
   - коммерческое использование в игре, на всех платформах, бессрочно, на территории всего мира;
   - использование в рекламе игры;
   - право редактировать фонограммы;
   - запрет или разрешение на обучение ИИ на этих записях (по согласованию);
   - согласие на дозапись в будущем.
4. Получить исходники WAV и подписанный договор. Положить их в `assets-src/audio/` и `assets/audio/LICENSES.md`.

**Вариант «TTS-сервис»:**
1. Прочитать действующие условия, сохранить PDF с датой.
2. Оформить платный тариф **до** генерации.
3. Создать голос через дизайн голоса сервиса или взять голос с понятной лицензией. Клон реального человека не использовать.
4. Сгенерировать реплики 1–12, по 3–5 дублей каждой. Сохранить ID голоса, настройки и текст с метками.
5. Скачать в максимальном качестве (WAV или лучший доступный формат), записать в `LICENSES.md`.

Файлы потом передаются мне (коммит в `assets-src/audio/agata/`), и я прогоняю их через конвейер §8.

## 6. ТЗ на запись
- Формат исходника: WAV PCM, 48 кГц, 24 бит, моно.
- По 3 дубля на реплику, пауза 2 с между дублями.
- Помещение без эха; без музыки, эффектов и обработки (шумоподавление — только деликатное).
- Ровная дистанция до микрофона во всех сессиях. Записать параметры, чтобы дозапись звучала так же.
- Имена файлов: `agata_<категория>_<ситуация>_<NN>_take<K>.wav`.
- Пиковый уровень исходника −6…−3 dBFS, без клиппинга.

## 7. Поведение в браузере и на устройствах
- Аудиоконтекст создаётся и разблокируется по первому действию пользователя (кнопка «Играть»). До этого звука нет, и обходить это ограничение нельзя.
- **Системный беззвучный режим уважается.** На iOS используем Web Audio без приёмов, которые позволяют играть звук при переключателе «Без звука». Если устройство на беззвучном, игра молчит.
- Пауза всего звука:
  - при `visibilitychange` (вкладка скрыта) и потере фокуса;
  - при показе рекламы;
  - по событию платформы `game_api_pause`.
  - Возобновление — только если звук был включён пользователем.
- Настройки: **общая громкость**, **голоса**, **эффекты** (музыка — позже), кнопка «Без звука». Хранятся в сохранениях. По умолчанию звук включён: игра стартует со звуком после первого клика.

## 8. Техническая схема
### 8.1 Конвейер ассетов (офлайн, `tools/audio`)
WAV (исходник) → обрезка тишины → нормализация громкости → кодирование → JSON-описание фаз рта для липсинка → `manifest.json` (длительность, размер, хэш).

Параметры **не фиксируются до измерений** на прототипе:
- **Громкость.** Гипотеза: −16 LUFS интегрально, пик −1 dBTP. Проверим на слух на телефоне и в наушниках.
- **Кодек.** Сравнить Opus 24/32/48 кбит/с и AAC 48/64 кбит/с: слепое прослушивание, размер, декодирование в Safari iOS, Chrome Android, Яндекс Браузере и десктопе. Итог — `docs/DECISIONS.md`.
- **Липсинк.** Сравнить два варианта на демо-репликах и выбрать по качеству и сложности:
  - Rhubarb Lip Sync (MIT, офлайн, фонетический режим для не-английских языков);
  - простое открытие рта по амплитуде.

### 8.2 Хранение
```
assets-src/audio/<lang>/<character>/*.wav       исходники (в сборку не входят; Git LFS — по решению)
public/audio/<lang>/<character>/*.{opus,m4a}    сборочные файлы (отдаются как есть)
public/audio/<lang>/<character>/manifest.json   какие реплики реально записаны: { "lines": { id: { "opus": файл, "m4a": файл } } }
assets/audio/LICENSES.md                        права на каждый файл; `npm run check:assets` (входит в `npm run check`) не пропускает файл без записи и манифест со ссылкой на отсутствующий файл
```
Реализация (2026-10-17):
- каталог реплик — `src/characters/agata/lines.ts`;
- режиссёр — `src/characters/director.ts`, связь с событиями партии — `src/games/durak/reactions.ts`;
- голосовой канал — `src/audio/voiceChannel.ts`;
- движок Web Audio — `src/audio/engine.ts`.

Реплика без файла в манифесте не выбирается: эмоция и поза отыгрываются молча, текст не выводится вместо голоса.

### 8.3 Каталог реплик
Каталог реплик — данные (`src/characters/agata/lines.ts`). Пример записи:
```ts
{ id: 'agata_trump_azart_01', category: 'beatWithTrump', emotion: 'azart',
  priority: 'reaction', when: { scoreTrend: 'any' }, cooldownSec: 90, weight: 1 }
```
`when` — условия контекста. Например, «только если игрок ведёт», «только после первой встречи». Это и есть защита от несоответствия ситуации.

### 8.4 Режиссёр реакций (персонаж)
1. Доменное событие партии.
2. Вероятность высказаться: зависит от характера и важности события.
3. Фильтр по условиям `when` и кулдаунам.
4. Выбор из «мешка без повторов» данной категории.
5. Заявка в голосовой канал с приоритетом.

Глобальный ограничитель: между некритичными репликами не меньше N секунд. N — параметр характера, у Агаты около 6–8 с.

### 8.5 Голосовой канал
- Одновременно звучит **одна** реплика персонажа.
- Приоритеты: `result` > `greeting`/`farewell` > `reaction` > `idle`.
- Более важная реплика прерывает менее важную (затухание ≈120 мс). Равная или менее важная ждёт в очереди не дольше TTL ≈1,5 с, иначе выбрасывается.
- Пока звучит голос, эффекты приглушаются на 3–6 дБ.
- Анимация рта и эмоция запускаются тем же событием, что и звук.
- Если звук выключен или файл недоступен, эмоция и анимация отыгрываются без звука, игра не ждёт.

### 8.6 Ошибки
- Файл не загрузился или не декодировался → реплика пропускается, ошибка пишется в отладочный журнал, категория помечается временно недоступной.
- Ошибка всего аудиоконтекста → игра продолжается без звука, в настройках отображается сообщение.
- Предзагрузка набора персонажа при выборе соперника; вспомогательные реплики догружаются лениво.

## 9. Учёт прав (`assets/audio/LICENSES.md`)
По каждому файлу или партии файлов:
- источник (актёр или сервис);
- исполнитель или ID голоса;
- дата;
- тариф;
- ссылка и копия условий или номер договора;
- разрешённое использование;
- ограничения.

Без записи в этом файле ассет в сборку не попадает: это проверяет скрипт сборки.

## 10. Оценка объёма
- Демо-набор: 12 файлов, ≈20 с речи.
- Полная библиотека Агаты для среза: ≈54 файла, ≈2 мин речи. Гипотеза по размеру — 0,5–1,5 МБ на формат, уточним измерением.

Почему Qwen3-TTS:

### 14.2 Схема генерации
1. VoiceDesign по описанию персонажа (`tools/voice/agata.voice.json`, поле `persona`) озвучивает эталонную фразу → `assets-src/audio/ru/agata/_reference.flac`.
2. Base строит из эталона подсказку голоса и озвучивает ею каждую реплику — **один тембр во всём каталоге** («Voice Design then Clone» из документации Qwen3-TTS). Эталон синтетический, поэтому это не клонирование живого человека.
3. Для проб есть второй режим (`--mode design`): каждая реплика — VoiceDesign с ремаркой эмоции из каталога. Игры голосом больше, но тембр может «плавать». Выбор режима — по прослушиванию.

Инструменты:
- `tools/voice/export-catalog.mjs` — тексты берутся только из каталога игры `src/characters/agata/lines.ts`;
- `tools/voice/generate.py` — генерация FLAC:
  - сид каждой реплики стабилен и зависит от её id;
  - рядом с файлом лежит `<id>.json`: текст, сид, модели, хэш;
  - вручную изменённый или закреплённый (`"locked": true`) файл не перезаписывается без `--force`;
  - режимы: `--samples`, `--all`, `--only <id>`, другой дубль — `--seed-offset N`;
  - отчёт — `_generate-report.json`;
- `tools/audio/build-voice.mjs` — сборка в игру:
  - обрезка тишины, громкость −16 LUFS / пик −1,5 dBTP (два прохода `loudnorm`);
  - кодирование: Opus 32 кбит/с (Chrome, Firefox, Яндекс Браузер) и AAC 48 кбит/с в `.m4a` (Safari/iOS) — движок сам выбирает формат через `canPlayType`;
  - поиск брака: тишина, клиппинг, длительность;
  - запись манифеста и строк в `assets/audio/LICENSES.md`;
  - отчёт `tools/voice/report/agata.md` — длительность, размеры, статус каждой реплики и реплики без голоса;
- проверки: `tests/audio/voiceManifest.test.ts` (манифест ↔ каталог ↔ файлы, настоящие контейнеры Opus/AAC) и `npm run check:assets` (права на каждый файл).

Установка и запуск (машина разработчика):
```bash
python -m venv .venv-voice && .venv-voice/bin/pip install -r tools/voice/requirements.txt
.venv-voice/bin/python tools/voice/generate.py --samples --out assets-src/audio/ru/agata/samples/clone
.venv-voice/bin/python tools/voice/generate.py --samples --mode design --out assets-src/audio/ru/agata/samples/design
# после одобрения голоса:
.venv-voice/bin/python tools/voice/generate.py --all
node tools/audio/build-voice.mjs
```
