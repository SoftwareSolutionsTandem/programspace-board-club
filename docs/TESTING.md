# Тестирование

## Автоматические проверки
| Проверка | Команда | Что ловит |
|---|---|---|
| Линтер | `npm run lint` | ошибки кода; **Math.random() и DOM в чистом коде** (`src/core`, `src/layout`, `src/games/*/rules`, `src/games/*/ai`, `src/games/*/view.ts`); **импорт полного состояния партии в ИИ** |
| Типы | `npm run typecheck` | строгий TypeScript (`strict`, `noUncheckedIndexedAccess`) |
| Тесты | `npm test` | Vitest, файлы `tests/**/*.test.ts`, окружение Node |
| Сборка | `npm run build` | production-сборка Vite |
| Всё сразу | `npm run check` | то же, что CI (`.github/workflows/ci.yml`) на каждый PR и push в `main` |

## Что покрыто сейчас
- `tests/core/rng.test.ts` — детерминизм ГСЧ, неизменяемость и JSON-сериализация состояния, диапазоны, равномерность `nextInt` и `shuffle`.
- `tests/i18n/i18n.test.ts` — подстановка параметров, откат на язык по умолчанию, неизвестный язык, форматирование чисел, отсутствие пустых строк в `ru.json`.

## Чего текущие проверки НЕ подтверждают
Смоук-проверка Playwright на 390×844 и 1280×720 (этап 1.1) подтверждает только, что **каркас экранов работает**:
- страница загружается без ошибок в консоли;
- создаётся canvas;
- экраны «старт» и «стол» переключаются.

Адаптивность и удобство компоновок она **не** проверяет. Компьютерной и телефонной компоновок партии пока нет.

- `tests/games/durak/cards.test.ts` — колода из 36, запись карт, младший козырь.
- `tests/games/durak/setup.test.ts` — раздача (6+6, 24 в колоде, козырь последним, все карты на месте, детерминизм), первый атакующий (младший козырь, «под дурака», ничья, нет козырей, козырь-подкладка не учитывается), пересдача, публичные знания, статистика пересдач и равенства мест; каждая карта ровно в одной зоне; воспроизводимость `newGame`; различие раздач по разным seed.

- `tests/games/durak/engine.test.ts` — правила: старшинство, атака, защита, подкидывание, лимиты (5/6 и рука защитника), бито, добор, взятие и подкидывание вдогонку, конец партии по всем строкам §6.1, отказ без изменения состояния.
- `tests/games/durak/series.test.ts` — счёт серии, «под дурака», ничья.
- `tests/games/durak/simulation.test.ts` — случайные партии законными ходами: инварианты на каждом шаге (300 партий), завершаемость и разнообразие исходов (10 000 партий), воспроизводимость.

- `tests/games/durak/ai.test.ts` — честность ИИ (проекция без скрытых данных, неразличимость решений при другой раскладке скрытых карт), законность и воспроизводимость, сила уровней.

- `tests/storage/settings.test.ts` — настройки: значения по умолчанию, сохранение, повреждённые данные, миграция, версия из будущего, недоступное хранилище.
- `tests/audio/voiceChannel.test.ts` — одна реплика за раз, TTL, прерывание по приоритету, отсутствие накопления, пропуск отсутствующего файла, отключение голоса.
- `tests/characters/director.test.ts` — каталог реплик (уникальность, демо-набор, нейтральность к полу), мешок без повторов, лимит болтовни, кулдаун, реплики без файла не выбираются, детерминизм.
- `tests/games/durak/reactions.test.ts` — события партии → реакция персонажа.
- `tests/games/durak/match.test.ts` — контроллер: полные партии на всех уровнях, серия, очерёдность, отказ без изменений, воспроизводимость, проекция без чужой руки.
- `npm run check:assets` — права на каждый аудиофайл.

## Ручная проверка в VS Code
1. `npm install`, затем `npm run dev`, открыть адрес из консоли.
2. Для телефонных размеров: DevTools → режим устройства (например, 390×844) и альбомная ориентация.
3. Отладка: `window.__game` в консоли браузера (только dev-сборка) — текущий экран и `show('start' | 'table')`.

Автотесты логики звука **не заменяют** прослушивание: качество голоса проверяется вручную на телефоне и в наушниках.
